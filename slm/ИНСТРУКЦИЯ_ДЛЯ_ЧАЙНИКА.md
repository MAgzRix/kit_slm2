# Инструкция для чайника: запуск на Windows (пошагово)

Читай по одному шагу. Делай строго как написано. Не торопись.

---

## ШАГ 0. Что у тебя где лежит

Ты скачал проект в папку `C:\ml`. Внутри неё есть папка `slm`, а внутри `slm` — все скрипты и данные.

Выглядит так:

```
C:\ml\
 └── slm\
      ├── tokenizer.py   <- эти файлы мы будем запускать
      ├── data.py
      ├── train.py
      ├── generate.py
      └── data\
           └── corpus.txt  <- текст, на котором учим
```

Твоя ошибка была простая: ты запускал команды из `C:\ml`, а скрипты лежат в `C:\ml\slm`. Компьютер искал `tokenizer.py` не там.

---

## ШАГ 1. Установить правильный Python (3.12)

У тебя стоит Python 3.14 — под него ещё нет PyTorch. Ставим 3.12 рядом, это нормально, пусть стоят оба.

1. Открой в браузере: https://www.python.org/downloads/release/python-31210/
2. Пролистай вниз до таблицы "Files". Нажми **Windows installer (64-bit)**. Скачается файл вида `python-3.12.10-amd64.exe`.
3. Запусти скачанный файл.
4. На ПЕРВОМ экране окна установки ОБЯЗАТЕЛЬНО поставь галочку **"Add python.exe to PATH"** (внизу окна). Без галочки ничего не получится.
5. Дальше жми "Install Now" и дождись конца.

Проверка:
1. Закрой VS Code полностью и открой заново (это важно, иначе он не увидит новый Python).
2. В VS Code открой терминал: меню `Terminal` → `New Terminal`.
3. Напиши в терминале и нажми Enter:

```
py -3.12 --version
```

Если ответило `Python 3.12.10` — всё хорошо, идём дальше.

---

## ШАГ 2. Установить PyTorch и нужные библиотеки

В том же терминале VS Code напиши одну команду целиком и нажми Enter (установка займёт несколько минут, что-то будет качаться — не пугайся):

```
py -3.12 -m pip install torch --index-url https://download.pytorch.org/whl/cpu
```

Потом второй командой:

```
py -3.12 -m pip install numpy requests
```

Проверка:

```
py -3.12 -c "import torch; print(torch.__version__)"
```

Если показала версию (например `2.5.1+cpu`) — отлично.

> Если у тебя видеокарта NVIDIA и хочется быстрее — скажи мне, дам команду для GPU. Но для начала CPU хватит.

---

## ШАГ 3. Перейти в правильную папку

В терминале VS Code напиши:

```
cd C:\ml\slm
```

Нажми Enter. Теперь ты «внутри» проекта. Проверь:

```
dir
```

Ты должен увидеть в списке файлы `tokenizer.py`, `train.py`, `generate.py` и папку `data`. Если видишь — всё правильно.

> Важно: каждый раз, когда открываешь новый терминал, нужно снова писать `cd C:\ml\slm`.

---

## ШАГ 4. Построить токенизатор

```
py -3.12 tokenizer.py --data data/corpus.txt --vocab 4096
```

Появится сообщение про словарь. Папка `tokenizer` создастся/обновится.

---

## ШАГ 5. Подготовить данные

```
py -3.12 data.py
```

Ответит что-то вроде: `ok: N tokens, train=..., val=...`. Это значит данные нарезаны в файлы train.bin / val.bin.

---

## ШАГ 6. Обучить модель

```
py -3.12 train.py --iters 2000
```

Это самый долгий шаг (на CPU примерно 20–40 минут). Будут печататься строчки со loss — чем меньше число, тем лучше учится. Можно пойти пить чай.

Хочешь быстро посмотреть результат — запусти сначала маленькую версию:

```
py -3.12 train.py --iters 300
```

---

## ШАГ 7. Сгенерировать текст

```
py -3.12 generate.py --prompt "Когда наступало" --tokens 100
```

Модель допишет текст сама. Первый результат будет бредовым или очень простым — это нормально, ты только начал. Больше данных + больше итераций = умнее модель.

---

## Частые проблемы

| Надпись в терминале | Что делать |
|---|---|
| `can't open file 'tokenizer.py'` | Ты не в той папке. Выполни `cd C:\ml\slm` |
| `'python' is not recognized` | Не поставил галочку Add to PATH. Используй `py -3.12` вместо `python` |
| `No module named torch` | Пропустил Шаг 2, выполни его |
| Качает/ставит медленно | Просто подожди, torch большой (~200 МБ) |
| Ошибка про кодировку текста | Сохрани corpus.txt в UTF-8 (в VS Code: правый нижний угол → Save with Encoding → UTF-8) |

---

## Как поменять текст для обучения

Открой файл `C:\ml\slm\data\corpus.txt` в VS Code, вставь туда свой текст (сказки, статьи, что угодно, от 0.5 МБ), сохрани (Ctrl+S). Затем повтори Шаги 4 → 5 → 6 → 7.
