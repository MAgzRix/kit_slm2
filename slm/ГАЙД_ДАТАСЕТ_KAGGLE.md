# Гайд для чайника: обучить SLM на своём датасете с Kaggle

Всё делаем в терминале VS Code. Каждая команда — одна строка, нажал Enter, ждёшь конца.

---

## Шаг 0. Установить kagglehub (один раз)

```
python -m pip install kagglehub
```

Если пишет ошибку про права/PATH — используй `py -m pip install kagglehub`.

---

## Шаг 1. Скачать датасет

Создай в папке slm файл `download_data.py` (правой кнопкой в дереве файлов → New File),
вставь туда ровно это:

```python
import kagglehub
path = kagglehub.dataset_download("ryemint/kit-knowledge-base")
print("ПУТЬ:", path)
```

Запусти:

```
python download_data.py
```

Подожди (зависит от размера датасета и интернета). В конце программа напечатает строчку:

```
ПУТЬ: C:\Users\админ\.cache\kagglehub\datasets\ryemint\kit-knowledge-base\versions\1
```

**ЭТО И ЕСТЬ ПУТЬ.** Скопируй его целиком мышкой (без кавычек не надо, но в шаге 2 кавычки нужны).

Если скачивание просит логин / ошибка 403:
1. Зайди на kaggle.com, зарегистрируйся
2. Справа сверху на аватарке → Settings → раздел API → «Create New Token» (скачается файл kaggle.json)
3. В Windows: создай папку `C:\Users\админ\.kaggle` и положи туда скачанный `kaggle.json`
4. Запусти `python download_data.py` заново

---

## Шаг 2. Превратить датасет в наш corpus.txt

Из папки slm (проверь командой `cd`, должно быть `c:\ml\workspace\slm`):

```
python prepare_dataset.py --src "C:\Users\админ\.cache\kagglehub\datasets\ryemint\kit-knowledge-base\versions\1"
```

ВАЖНО: вместо пути в кавычках вставь тот путь, который напечатал Шаг 1. Кавычки обязательны,
если в пути есть пробелы или русские буквы.

Хороший признак — программа напечатает что-то вроде:

```
Документов: 12,345 | знаков: 890,123 | уникальных слов: 15,000
Записано в data/corpus.txt...
```

Если написано «Ничего текстового не найдено» — пришли сюда вывод команды `dir <путь>` из Шага 1,
разберёмся, в каком там формате данные.

## Шаг 3. Токенизатор

```
python tokenizer.py --data data/corpus.txt --vocab 4096
```

Должно напечатать `Готово. vocab=... тип=word -> tokenizer/` (или BPE, если стоит minbpe).

## Шаг 4. Нарезать данные

```
python data.py
```

Напечатает количество токенов train/val. Если токенов мало (< 50 000) — это маленький датасет,
в следующем шаге добавь `--block-size 64`.

## Шаг 5. Обучение

```
python train.py --iters 500 --block-size 64
```

Пошли строчки `iter 50/500 | loss ...`. Loss должен уменьшаться (например 3.5 → 2.1 → 1.4).
На CPU 500 итераций ≈ 10–20 минут. Это нормально, можно пойти попить чаю.
Прервать можно Ctrl+C, потом продолжить: `python train.py --iters 1000 --resume out/best.pt`.

Когда закончится — напишет `Готово за ... мин. Лучший val loss: ...`.

## Шаг 6. Поговорить с моделью

```
python generate.py --prompt "Машинное обучение" --tokens 150
```

(подставь в --prompt любое начало фразы из твоего датасета — так лучше работает)

## Частые болячки

| Симптом | Лечение |
|---|---|
| `ModuleNotFoundError: No module named 'X'` | `python -m pip install X` (X = numpy, torch, requests, kagglehub) |
| `can't open file ... prepare_dataset.py` | ты не в той папке. Выполни `cd c:\ml\workspace\slm` |
| Скачивание Kaggle висит | датасет большой — просто жди; или проверь интернет |
| Модель генерирует бред | мало данных/итераций: `--iters 2000`; или слишком маленький датасет |
| CUDA error / нет видеокарты | ты на CPU, всё ок, просто медленнее |

## Ожидай честно

На датасете базы знаний модель выучит **стиль и термины**, но не будет «умным помощником,
отвечающим на вопросы». Это next-word-модель: она дописывает текст похожий на твой корпус.
Чтобы отвечать вопросами на вопросы — следующий уровень: собрать пару «вопрос → ответ»
и обучить модель начинать ответ после вопроса (mini-instruct). Обсудим, когда этот этап пройдёшь.
